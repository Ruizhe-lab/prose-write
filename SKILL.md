# Writing: entry

Edition: public, November 2026 rebuild (see [EXPORT_NOTES.md](EXPORT_NOTES.md)).
- Each decision is stated once, in a table.
- The team, the message, approval and the record: the team file.
- The plan, the card and the send check: the unit file.

This file routes. It decides nothing else.
Any writer who shows the author prose reads Core first. Every brief names this edition, the job and the type.
This skill covers one section or one text. Planning a whole paper is a separate job.

Core = this file, [the team file](HOW_WE_WORK.md), [the standard](STANDARDS.md), [the unit file](references/unit-plan-card-gate.md).

## Order of authority

1. The author's latest words on the same subject and scope.
2. The author's standing principles, as the project record holds them.
3. The practice of the team file: the writer the author talks to leads and writes; a partner writes its own version; the author sees the current text and the versions that the team file's "One message" table gives (three for a live part); everything is checked first.
4. The scientific rules of the host project. No writing rule loosens them. Prose from reviewed research needs no new summary of the paper: the lead reads the agreed one if the project has it.
5. Craft written by the writers, and the lead's defaults.

A later word wins only on the same subject and scope.
